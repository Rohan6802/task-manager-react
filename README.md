# Task Manager - MERN Stack Application

A full-stack task management application with authentication and user-specific task management.

## Links

- Live Demo: https://task-manager-react-three-kappa.vercel.app
- Github Repo:https://github.com/Rohan6802/task-manager-react.git

## Features

- User Registration & Login
- JWT Authentication
- Password Encryption with bcrypt
- Create Tasks
- Update Tasks
- Delete Tasks
- Mark Tasks Complete
- Search Tasks
- Filter Tasks
- Sort Tasks
- Due Dates
- Task Statistics
- User Specific Data

## Tech Stack

Frontend:

- React
- Axios
- React Router

Backend:

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

## Project Structure

Client - React frontend  
Server - Express backend

## Installation

Clone Repository

npm install
